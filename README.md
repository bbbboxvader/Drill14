# Drill 14: 새 비행 애니메이션

## 실행

프로젝트 폴더에서 `python -m pip install pico2d PySDL2 PySDL2-dll transitions`로 패키지를 설치하고 `python main.py`를 실행합니다. 이미지 파일은 프로젝트 폴더에 그대로 두세요. 방향키로 소년을 움직이고 Esc로 종료합니다.

## 동작

- 새 열 마리가 두 줄로 배치되어 화면의 양쪽 끝 사이를 반복해서 비행합니다.
- `bird_animation.png`의 14개 프레임을 왼쪽 위에서 오른쪽으로, 다음 줄 순서로 반복합니다.
- 화면 끝에서 이동 방향과 이미지 방향을 바꿉니다.
- 이동과 애니메이션에 프레임 경과 시간을 적용합니다.

## 프레임 속도 계산

예시 그림과 같은 방식으로 속도, 한 번의 날갯짓 동안 이동하는 거리, 프레임 수를 사용합니다. 이 값은 시뮬레이션을 위한 가정이며 실제 새의 측정값이 아닙니다.

1. 새 속도: 7 km/h = 7 × 1000 ÷ 3600 ≈ 1.944 m/s
2. 날갯짓 한 번의 이동 거리: 0.8 m
3. 날갯짓 한 번의 시간: 0.8 ÷ 1.944 ≈ 0.411초
4. 날갯짓 한 번에 14프레임: 14 ÷ 0.411 ≈ 34.03 FPS
5. 매 업데이트마다 `frame += FPS × frame_time`을 적용하고 14로 나눈 나머지로 반복합니다.

이동 속도도 같은 경과 시간을 사용합니다. 기존 소년의 화면 축척인 10픽셀 = 0.3m를 적용하여 초당 약 64.81픽셀 이동하며, 양쪽 경계에서 넘어간 거리만큼 반대쪽으로 되돌려 프레임 시간에 따른 위치 오차를 줄입니다.
